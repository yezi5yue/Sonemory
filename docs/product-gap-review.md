# 学生学习与家长管理功能缺口评估

版本：v0.6（2026-08-15）

## 本轮已补齐

### 学生学习

- 课程按大类、子类筛选，也可在课程选择器内跨分类搜索。
- 课程下先选择资料，再按资料中的 `unit` 指定本次学习范围。
- 选择区显示本范围总数、已练习数和待巩固数，避免在开始前不知道将学什么。
- 会话快照记录资料和单元范围，暂停恢复时不会误入另一单元。
- 浏览器按钮和语音“暂停”都会立即中断当前播报或识别。

### 家长资料管理

- 导入资料时按“大类 → 子类 → 课程”三级联动确认归属。
- 课程可以编辑名称、说明、大类和子类；资料编辑时可以移动所属课程。
- 支持 CSV/XLSX 文件、粘贴内容、格式校验、前五项预览和模板下载。
- 内容资料卡片展示总项数、已练习数和待巩固数，并支持导出 CSV 后再删除。
- XLSX 在浏览器本地解析，限制为第一个工作表、10 MB、10,000 条；不因解析而上传文件。

### P0 数据安全、可解释性与语音兜底

- “学习设置”可下载完整 JSON 备份，覆盖资料库、设置、暂停会话、最近记录和逐项进度；恢复前校验版本和引用关系。
- 恢复支持“替换全部”及“合并新增、同 ID 保留本机”，并在写入失败时回滚。
- 每份资料可打开逐项明细，区分答对、答错、识别失败和提示使用，并展示最近结果与建议。
- 连续识别失败时会语音引导重试、检查麦克风设备与权限；仍不能恢复时自动切换为只听跟读，不把技术失败计为知识错误。

## 仍需按优先级推进

| 优先级 | 角度 | 缺口 | 建议 |
|---|---|---|---|
| P1 | 家庭 | 多个孩子共用设备时记录会混在一起 | 增加纯本地学习者档案，课程资料可共享，进度按学习者隔离 |
| P1 | 学生 | 当前轮转进度不等同于科学的间隔复习 | 引入可解释的复习到期时间、熟练度和遗忘风险模型，并保留手动重置 |
| P1 | 家长 | Excel 列名写错时只能报缺列 | 增加列映射界面、重复项处理策略和导入前后差异摘要 |
| P1 | 跨学科 | 数据模型仍以 `word/meaning/partOfSpeech` 命名 | 演进为通用 prompt/answer/explanation 模型，并提供英语字段兼容层 |
| P2 | 家长 | 删除只能依赖浏览器确认框，缺少回收站 | 增加短期本地回收站和可恢复删除，同时限制存储占用 |
| P2 | 家庭 | 缺少可选择的跨设备同步 | 在保持本地优先的前提下设计端到端加密、显式授权的同步适配器 |

## 实施边界

P0 已在 v0.6 完成。下一步应单独设计多学习者或跨学科通用模型的存储迁移，不与同步同时实施。云同步和儿童数据分析不应默认开启；逐项明细是学习表现记录，不应表述为医学、能力或永久掌握结论。
