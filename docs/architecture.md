# 系统架构

## 目标

v0.1 以最少依赖验证一个问题：儿童能否在家长完成一次设置后，仅靠听和说独立完成一组英语单词练习。

## 模块

```text
CSV / XLSX ──> 本地解析与预览 ──> 校验与标准化 ──> 大类 ──> 子类 ──> 课程 ──> 内容资料 ──> 单元范围
                                                                    │
                                                                    v
设备端/浏览器识别 ──> 命令解析 ──> 学习状态机 ──> 语音合成
                                    │
                                    ├──> 延迟重试队列
                                    └──> 分课程/资料的本地报告
```

- `src/content.js`：CSV 解析、字段清洗、来源元数据和重复项校验。
- `src/importers.js`：限制文件大小、读取 CSV、在浏览器本地解压 XLSX 第一个工作表并转换为统一 CSV；不依赖云端解析服务。
- `src/engine.js`：课程队列、答案判断、重试调度、会话快照和统计口径。
- `src/speech.js`：浏览器语音合成、语音识别与能力检测的薄封装。
- `src/speech.js` 同时实现 Speech Gateway Protocol v1 客户端；TTS 与 STT 可以独立切换到 AI/自托管网关，平台适配与长期密钥留在网关服务端。
- `src/storage.js`：版本化的浏览器本地存储、旧资料库到四级内容模型的迁移、课程搜索与学习范围选择。
- `src/backup.js`：完整本地备份的格式校验、引用预检、冲突摘要和保留本机的合并规则。
- `src/app.js`：学生学习、资料管理、语音设置和报告视图的协调层。

## 内容资料模型

`sonemory.library.v3` 保存大类、子类、课程和资料四个列表，实体之间只通过 ID 关联。大类和子类由用户在本地自定义，课程必须同时归属一个匹配的大类和子类；每份资料保存自己的来源、版本、语言和学习项。`sonemory.selection.v1` 保存当前完整层级与资料 ID，学习会话、掌握度和历史仍按资料 ID 隔离。

从 v0.2 升级时，原课程和资料 ID 不变，课程统一归入“未分类 / 默认分类”；从 v0.1 升级时，原来的 `sonemory.pack.v1` 会被复制到该层级下的“默认课程”。因此原学习进度仍可继续。编辑资料时，资料 ID 不变；名称相同的词条也会保留原条目 ID，新条目生成新 ID，被删除条目的旧进度不再参与学习。

学习页严格按“大类 → 子类 → 课程”过滤下一层选项，未选课程时不加载资料。课程搜索会匹配课程名称和说明，命中后通过课程保存的外键一次恢复完整层级，避免在多个同名子类之间定位错误。选定资料后还可按学习项的 `unit` 字段缩小本次范围；会话快照同时记录资料 ID 和单元范围，避免错误恢复到另一范围。

资料导入表单使用独立的大类、子类、课程三级联动，保存时仍以课程 ID 为唯一外键。课程编辑允许在合法层级之间移动课程，资料编辑允许移动所属课程；子级 ID 不因移动而改变，因此资料和学习进度仍可保持关联。格式和限制见 [内容资料导入与管理](content-import.md)。

## 学习状态

单词依次经过 `intro → explain → chunk → imitate → recall → feedback`。答错或选择“不会”后，系统给出纠正示范，并把该词延迟放回队列。达到单次最大重试次数后结束本轮，避免无限循环。

识别超时、无匹配或引擎错误记为 `recognitionFailures`，不会增加 `incorrect`。这是重要的产品边界：麦克风或识别器失败不等于孩子不会。

提示、拼读、慢速示范和只听跟读记为 `assisted`，不再混入 `incorrect`。逐项进度累计 `correct`、`incorrect`、`recognitionFailures`、`assisted`、`attempts`、`lastOutcome` 和 `lastPracticedAt`；旧进度缺少的新字段按 0 或空值兼容。

连续两次识别不到有效文本时，协调层会先执行只检查设备/权限的麦克风自检，再通过语音请求“再试一次”或“只听跟读”。恢复指令仍失败时，当前会话自动进入只听跟读：继续提示、留出回答时间并核对答案，但不做语音正确性判断。该状态写入暂停会话，恢复后保持一致。

## 本地备份边界

备份格式 `sonemory-local-backup` 当前 `schemaVersion` 为 1，包含 `library`、`selection`、`settings`、`session`、`history` 和 `progress`。恢复前必须验证资料库 schema、实体 ID 唯一性、大类/子类/课程/资料引用、学习项 ID、选择和暂停会话引用。替换恢复采用写入前快照，任何异常都会回滚；合并恢复只加入新 ID，同 ID 始终保留本机数据。临时 AI Token 从不进入设置存储，因此也不会进入备份。

## 内容边界

仓库只提供内容格式和极少量非教材演示数据。生产内容包由家庭或学校依据合法来源生成，项目不抓取、不镜像、不推断特定教材正文。

## 隐私边界

- 默认不注册账号、不设置云端身份。
- 默认不保存原始音频。
- 学习记录仅在浏览器本地；清除站点数据即可移除。
- Web Speech 实现可能把音频交给浏览器厂商服务，产品界面必须如实提示。
- 只有在浏览器确认设备端语言包可用、且识别对象启用 `processLocally` 时，产品才显示为设备端识别；自动模式无法使用本地语言包时会回退到浏览器默认服务。
- AI 网关是明确选择的外部处理边界：临时访问令牌只存在于页面内存，启用 STT 前必须记录家长确认；远程端点强制 HTTPS，本机开发端点可使用 HTTP。

## 许可与产品边界

- 本仓库核心代码按 `AGPL-3.0-only` 发布；修改版通过网络提供给用户或向外分发时，需要根据 AGPL 评估并履行源码与通知义务。
- 用户导入的词表、教材内容和学习记录不是因为进入 Sonemory 就自动变成 AGPL 内容，其权利与合规责任仍由内容本身的来源决定。
- 浏览器提供的 Web Speech API 不是仓库分发的组件；未来引入本地 ASR/TTS、模型、SDK、字体或数据集前，必须同时核对 AGPL 兼容性和闭源商业再许可权。
- 专有服务与 AGPL 核心之间的 API、进程或容器边界不能单独决定法律上的作品边界。计划形成闭源组合产品时，应保留接口、打包和部署设计记录，并在发布前进行个案许可审查。
- Sonemory 名称、Logo 和音频标识不包含在代码许可中；衍生发行版应遵守 [商标政策](../TRADEMARKS.md)。

具体决策、场景矩阵和发布检查见 [许可策略与影响评估](licensing-strategy.md)。

## 后续演进

跨学科扩展应复用 `内容项 → 提示 → 作答 → 反馈 → 复习` 协议，而不是把英语专用判断硬编码到核心状态机。离线语音识别与可替换 TTS 应通过适配器加入，使隐私模式与轻量浏览器模式可以共存。

语音引擎选型、性能预算与准确率验证见 [设备端语音识别评估](speech-roadmap.md)。
