# 学习设计说明

Sonemory 把学习科学当作可检验的设计输入，而不是营销承诺。v0.1 只实现风险较低、容易解释的基础机制。

## 当前采用的机制

### 提取练习

在给出中文释义后，请孩子主动说出英文，而非只重复听。这与提取练习研究的总体方向一致：主动回忆通常比重复阅读更有利于长期保持。参考：[Karpicke & Roediger, 2008](https://doi.org/10.1126/science.1152408)。

### 延迟再试

答错的词不会立刻连续轰炸，而是插回稍后的队列。儿童词汇学习研究比较过重复、提取与间隔条件，为“隔开后再回忆”提供了设计依据。参考：[Goossens et al., 2014](https://doi.org/10.1002/acp.2956)；更长期的间隔效应可参考 [Bahrick et al., 1993](https://doi.org/10.1111/j.1467-9280.1993.tb00571.x)。

### 说出来

流程要求孩子跟读和作答，而不是只听。朗读带来的“产生效应”是设计依据之一，但产品是否在目标年龄、家庭噪声和中文母语场景中产生同等收益，仍需实测。参考：[MacLeod et al., 2010](https://doi.org/10.1037/a0018785)。

### 纠正反馈

答错后立即提供简短正确示范，再安排一次延迟机会。系统不羞辱、不连续扣分，也不把识别器失败算成知识错误。

## 暂不声称的效果

- 不声称能替代教师、系统课程或专业的语言评估。
- 不把语音识别结果当作可靠的发音评分。
- 不声称某个固定复习间隔对所有儿童和所有学科最优。
- 不依据一次短期正确率推断长期掌握。

## 后续验证建议

1. 先测可用性：完成率、主动求助率、识别失败率和家长介入次数。
2. 再测即时学习：首次回忆正确率、纠正后正确率和会话时长。
3. 最后测保持：隔天、隔周的独立回忆，并与等时长的普通跟读进行比较。
4. 所有儿童研究都应取得监护人知情同意，最小化数据采集，并优先记录汇总指标而非声音。

在没有足够样本与对照前，产品报告应使用“本次练习表现”，避免使用“永久掌握”“记忆力提升”等结论性措辞。
