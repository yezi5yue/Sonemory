# 内容资料导入与管理

## 推荐流程

1. 先在“资料管理”创建大类和子类。
2. 新建课程时选择匹配的大类、子类；已有课程可以通过“编辑归属”调整名称、说明和层级。
3. 在“导入新资料”中再次按“大类 → 子类 → 课程”确认归属，避免同名课程选错。
4. 填写资料名称、发布机构、版本和补充来源说明。
5. 上传 CSV/XLSX，或粘贴 CSV/竖线分隔内容；先点击“校验并预览”，确认后保存。
6. 保存后可在资料列表中设为学习内容、继续编辑、导出 CSV 或删除。

## 模板与格式

- [CSV 模板](../templates/sonemory-import-template.csv)
- [XLSX 模板](../templates/sonemory-import-template.xlsx)

XLSX 只读取第一个工作表。第一行必须包含字段名，`word` 和 `meaning` 必填；`partOfSpeech`、`unit`、`chunks`、`aliases`、`note`、`locale` 均可选。词组可以不填词性。

| 字段 | 用途 |
|---|---|
| `word` | 单词、词组或需要作答的文本 |
| `meaning` | 释义或回忆提示 |
| `partOfSpeech` | 词性；空值显示为“未标注” |
| `unit` | 学生端可选择的学习范围；空值归入“未分组” |
| `chunks` | 使用 `|` 分隔的拼读块 |
| `aliases` | 使用 `|` 或 `；` 分隔的可接受答案 |
| `note` | 家长备注、用法或例句 |
| `locale` | BCP-47 发音代码，例如 `en-US` |

限制：文件最大 10 MB；单份资料最多 10,000 条；旧版 `.xls` 需要先另存为 `.xlsx`。XLSX 导入在浏览器本地解压并转换，不会因为解析文件而上传内容。

## 更新、归属与进度

- 编辑资料时可以通过三级选择器把资料移动到其他课程。
- 更新时资料 ID 保持不变；同名学习项保留原学习项 ID，因此已有练习结果可以继续关联。
- 删除资料会同时删除该资料的本地进度；删除动作不可撤销，建议先导出 CSV 备份。
- 学生端可以在选定资料后继续按 `unit` 选择本次范围，并查看本范围总数、已练习数和待巩固数。

## 内容与版权边界

模板中的示例是项目自建演示内容，不对应教材。请只导入有权使用的官方资料、家庭自建内容或已获授权的内容；不要把教材正文或受保护词表提交到公共仓库。
