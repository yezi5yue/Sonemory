# Sonemory

> **Listen. Practice. Remember.**
>
> **声声入忆｜无屏语音陪学与记忆训练**

Sonemory（发音：**so-NEM-uh-ree**）是一个本地优先、音频优先的开源陪学项目。第一阶段聚焦英语单词：孩子无需持续看屏幕，就能独立完成“听发音 → 听释义与词性 → 跟读 → 回忆 → 纠错 → 延迟重试”的学习闭环。

> 项目不内置、不分发教材或教辅内容。家长、教师应从有权使用的官方来源取得词表，再自行导入。仓库中的演示词仅用于展示软件能力，不对应任何教材。

## 当前能力

- 音频主导的儿童学习模式，提供开始、暂停、重复、慢一点、拼写、提示、跳过和结束等语音指令。
- 自然发音、词性、中文释义、拼读分块、跟读和中文提示回忆。
- 把“没有听清”与“确实答错”分开处理，避免误判打击学习积极性。
- 连续识别失败时通过语音引导重试、麦克风设备/权限自检，并可临时切换为不判对错的“只听跟读”。
- 错词延迟插回队列，单次学习有明确结束点，不会无限循环。
- 资料库支持本地自定义“大类 → 子类 → 课程 → 内容资料”，课程可调整完整归属，资料可移动、更新、导出和删除。
- 学习开始前通过三级联动选择课程及内容资料；点击课程选择器后可直接输入名称筛选，跨分类命中时自动定位其大类和子类。
- 支持 CSV/XLSX 文件、粘贴内容、导入预览和可下载模板；导入时按大类、子类、课程确认归属，并要求填写来源名称、发布方和版本信息。
- 学生可在选定资料后继续按 `unit` 指定学习范围，并查看本范围的已练习和待巩固概览。
- 新版 Chromium 可检测并安装设备端语音语言包；可选择设备端优先、仅设备端或浏览器默认识别。
- 可分别接入 AI / 自托管 TTS 与 STT 网关：先替换播放或识别均可；长期平台密钥不写入浏览器，儿童作答音频上传必须由家长明确确认。
- 学习记录和设置只存储在当前浏览器；默认不保存孩子的原始录音。
- 可一键下载包含资料、设置、暂停会话、进度和记录的 JSON 备份；恢复前先预检，并支持整库替换或保留本机冲突的合并恢复。
- 家长可从每份资料查看逐项累计明细，分别核对答对、答错、未听清、提示使用、最近结果和复习建议。
- 安装为 PWA 后可离线打开；只有在设备端语言包就绪并实际启用时，才能保证识别不依赖远端服务。

## 快速开始

要求 Node.js 20 或更高版本。项目没有第三方运行依赖。

```bash
npm start
```

然后访问 `http://127.0.0.1:4173`。首次体验可进入“资料管理”，依次新建大类、子类和课程，再导入自己的资料；也可手动添加明确标注的非教材演示资料。

如果浏览器曾打开过旧版本，可访问 `http://127.0.0.1:4173/?v=0.6.0` 完成一次缓存升级；此后联网时会优先获取新版本，断网时才使用离线缓存。Sonemory 会把 v0.2 课程自动归入“未分类 / 默认分类”，把更早的唯一词表放入其下的“默认课程”，并保留课程、资料、设置、进度与学习记录。

运行校验：

```bash
npm test
npm run check
```

## 导入官方词表

可直接下载 [CSV 模板](templates/sonemory-import-template.csv) 或 [XLSX 模板](templates/sonemory-import-template.xlsx)。CSV 使用 UTF-8 编码；XLSX 读取第一个工作表。首行必须包含以下字段：

```csv
word,meaning,partOfSpeech,unit,chunks,aliases,note,locale
apple,苹果,名词,Unit 1,ap|ple,,,en-US
beautiful,美丽的,形容词,Unit 2,beau|ti|ful,,,en-US
```

- `word`、`meaning` 为必填列；`partOfSpeech` 可留空，系统会显示“未标注”。
- 直接粘贴时也兼容 `word | meaning | partOfSpeech` 三列格式，并允许表头仍使用逗号。
- `chunks` 使用 `|` 分隔自然拼读块；不填写时会按字母逐个拼读。
- `aliases` 使用 `|` 分隔可接受答案。
- `unit` 会成为学生端可选的学习范围；不填写时归入“未分组”。
- 常见词典记号会在音频中展开：`sth` 读作 `something`，`sb` 读作 `somebody`；例如 `run low (on sth)` 会读作 `run low on something`，回答时完整形式和省略括号形式都可接受。
- 导入前还必须填写来源名称、发布方和版本/学期，便于家庭自行追溯。
- 请仅导入你有权使用的内容，不要把受版权保护的教材词表提交到本仓库。

文件最大 10 MB，单份资料最多 10,000 条；旧版 `.xls` 请先另存为 `.xlsx`。完整流程见 [内容资料导入与管理](docs/content-import.md)。

## 课程与资料管理

1. 在“资料管理”中本地自定义大类和子类，例如“学校课程 → 语言类”。
2. 在对应子类中新建课程，例如“八年级英语”或“科学知识点”；点击“编辑归属”可移动课程并更新说明。
3. 导入资料时再次选择大类、子类和课程，上传 CSV/XLSX 后先校验预览；每份资料独立记录来源、版本、内容和学习进度。
4. 点击“编辑内容”可重新载入完整内容并移动所属课程；词条名称未改变时会保留原有词条 ID。删除前可导出 CSV 备份。
5. 点击“用于学习”，或在学生学习页依次选择大类、子类、课程、资料和 `unit` 范围。点击课程后会出现输入框：空输入显示当前子类课程，输入名称后可跨分类搜索并自动定位完整层级。
6. 删除资料会同时删除该资料的本地进度；有下级内容时不能删除课程、子类或大类，避免误删。
7. “学习明细”按词条展示答对、答错、未听清和提示使用次数；清除或迁移浏览器数据前，可在“学习设置”下载完整 JSON 备份。

## 本地备份与恢复

在“学习设置 → 完整本地备份”中下载 JSON 文件。恢复时应用会先检查备份版本、四级资料关系、学习项 ID、当前选择和暂停会话引用，再显示内容数量和同 ID 冲突数。

- “替换当前全部数据”用于整机迁移或完整回滚，会覆盖当前资料、设置、进度和记录。
- “合并新增”只加入备份中本机尚不存在的 ID；冲突项保留本机版本，避免静默覆盖。
- 恢复写入发生错误时会回滚到操作前状态。备份不包含临时 AI 令牌和原始录音，但仍可能包含儿童学习记录，应存放在家长控制的位置。

## 无屏交互说明

开始学习后，应用会朗读当前步骤并启动语音识别。孩子可说：

`开始`、`继续`、`重复`、`慢一点`、`拼写`、`什么意思`、`不会`、`下一个`、`再试一次`、`麦克风检测`、`只听跟读`、`暂停`、`结束学习`。

连续两次未识别到回答时，Sonemory 会用语音说明正在自检麦克风，并询问“再试一次”或“只听跟读”；恢复指令仍无法识别时自动进入只听跟读，本次继续播放提示、留出回答时间并给出答案，但不会把识别失败算成知识错误。

Web Speech API 的可用性与准确度因浏览器、设备、语言包、网络、儿童音色和环境噪声而异。目前建议使用新版 Chromium 浏览器，由家长在“学习设置”中先检测设备端语言包，并完成一次真实环境短测。“设备端”主要解决隐私、延迟和离线能力，并不自动保证比云端模型更准确。

当前版本会向支持的识别器提供目标词及常用英语指令作为上下文偏置，并检查最多五个候选结果。完整的本地识别技术比较、测量指标和后续路线见 [设备端语音识别评估](docs/speech-roadmap.md)。

AI 语音接入使用统一网关协议，不把任何云平台 SDK 或模型绑定到前端。接口规范、Azure/OpenAI/腾讯云/讯飞/ElevenLabs 与 sherpa-onnx/FunASR/whisper.cpp 的比较见 [AI 语音接入与选型](docs/ai-speech-integration.md)。

## 设计原则

1. 学习流程由可测试的确定性状态机驱动，AI 服务不是完成课程的前提。
2. 屏幕用于资料管理、学习设置与必要兜底，孩子的主流程以听和说完成。
3. 内容与引擎分离，官方教材内容由使用者合法导入。
4. 默认最小化儿童数据：不注册、不上传、不保存原始录音。
5. 记忆策略逐步验证后再采用，不承诺未经测量的学习效果。

更多细节见 [系统架构](docs/architecture.md)、[学习设计](docs/learning-design.md) 与 [学生/家长功能缺口评估](docs/product-gap-review.md)。后续维护者或 AI agent 请从 [项目交接文档](AGENTS.md) 开始。

## 路线图

- v0.1：英语单词音频学习闭环、CSV 导入、本地学习报告。
- v0.2：课程与资料库、资料内容更新、学习范围选择、设备端 Web Speech 语言包管理。
- v0.3：大类/子类/课程/资料四级管理、三级联动选择、课程名称搜索与旧数据迁移。
- v0.4：课程内嵌搜索组合控件、可插拔 AI TTS/STT 网关、录音降噪约束与轻量 VAD。
- v0.5：资料导入三级归属、CSV/XLSX 文件与模板、导入预览、课程归属编辑、资料导出、按单元学习。
- v0.6：完整本地备份/恢复、逐项错误原因与提示明细、识别失败的纯语音恢复和只听跟读降级。
- v0.7：真实儿童语音基准、sherpa-onnx/FunASR/云端语音引擎对比。
- v0.8：间隔复习、掌握度模型、匿名且可选择加入的效果评估。
- 后续：扩展到语文、数学、科学、历史、地理等适合听觉回忆的知识点；所有学科仍坚持内容授权与来源可追溯。
