# Sonemory

> **Listen. Practice. Remember.**
>
> **声声入忆｜无屏语音陪学与记忆训练**

Sonemory（发音：**so-NEM-uh-ree**）是一个本地优先、音频优先的开源陪学项目。第一阶段聚焦英语单词：孩子无需持续看屏幕，就能独立完成“听发音 → 听释义与词性 → 跟读 → 回忆 → 纠错 → 延迟重试”的学习闭环。

> 项目不内置、不分发教材或教辅内容。家长、教师应从有权使用的官方来源取得词表，再自行导入。仓库中的演示词仅用于展示软件能力，不对应任何教材。

## 当前能力

- 音频主导的儿童学习模式，提供开始、暂停、重复、慢一点、拼写、提示、跳过和结束等语音指令。
- 自然发音、词性、中文释义、拼读分块、跟读和中文提示回忆。
- 把“没有听清”与“确实答错”分开处理，避免误判打击学习积极性。
- 错词延迟插回队列，单次学习有明确结束点，不会无限循环。
- 资料库支持自定义课程、每门课程下多份内容资料、已有资料内容更新和删除。
- 学习开始前可以明确指定课程及内容资料，报告同步记录这两个维度。
- 支持 CSV 导入，并要求填写来源名称、发布方和版本信息；更新资料时保留相同词条的学习进度标识。
- 新版 Chromium 可检测并安装设备端语音语言包；可选择设备端优先、仅设备端或浏览器默认识别。
- 学习记录和设置只存储在当前浏览器；默认不保存孩子的原始录音。
- 安装为 PWA 后可离线打开；只有在设备端语言包就绪并实际启用时，才能保证识别不依赖远端服务。

## 快速开始

要求 Node.js 20 或更高版本。项目没有第三方运行依赖。

```bash
npm start
```

然后访问 `http://127.0.0.1:4173`。首次体验可进入“资料管理”，新建课程后导入自己的资料，或手动添加明确标注的非教材演示资料。

如果浏览器曾打开过旧版本，可访问 `http://127.0.0.1:4173/?v=0.2.0` 完成一次缓存升级；此后联网时会优先获取新版本，断网时才使用离线缓存。Sonemory 会把旧版唯一词表自动放入“默认课程”，并继续迁移同一来源下旧版 OpenRecall 的设置、进度与学习记录。

运行校验：

```bash
npm test
npm run check
```

## 导入官方词表

CSV 使用 UTF-8 编码，首行必须包含以下字段：

```csv
word,meaning,partOfSpeech,unit,chunks,aliases,note,locale
apple,苹果,名词,Unit 1,ap|ple,,,en-US
beautiful,美丽的,形容词,Unit 2,beau|ti|ful,,,en-US
```

- `word`、`meaning` 为必填列；`partOfSpeech` 可留空，系统会显示“未标注”。
- 直接粘贴时也兼容 `word | meaning | partOfSpeech` 三列格式，并允许表头仍使用逗号。
- `chunks` 使用 `|` 分隔自然拼读块；不填写时会按字母逐个拼读。
- `aliases` 使用 `|` 分隔可接受答案。
- 常见词典记号会在音频中展开：`sth` 读作 `something`，`sb` 读作 `somebody`；例如 `run low (on sth)` 会读作 `run low on something`，回答时完整形式和省略括号形式都可接受。
- 导入前还必须填写来源名称、发布方和版本/学期，便于家庭自行追溯。
- 请仅导入你有权使用的内容，不要把受版权保护的教材词表提交到本仓库。

## 课程与资料管理

1. 在“资料管理”中新建自定义课程，例如“八年级英语”或“科学知识点”。
2. 为课程导入一份或多份内容资料；每份资料独立记录来源、版本、内容和学习进度。
3. 点击“编辑内容”可重新载入完整 CSV，修改后覆盖保存；词条名称未改变时会保留原有词条 ID。
4. 点击“用于学习”，或在学生学习页使用两个下拉框，指定本次课程和内容资料。
5. 删除资料会同时删除该资料的本地进度；删除课程前必须先删除或移动其资料。

## 无屏交互说明

开始学习后，应用会朗读当前步骤并启动语音识别。孩子可说：

`开始`、`继续`、`重复`、`慢一点`、`拼写`、`什么意思`、`不会`、`下一个`、`暂停`、`结束学习`。

Web Speech API 的可用性与准确度因浏览器、设备、语言包、网络、儿童音色和环境噪声而异。目前建议使用新版 Chromium 浏览器，由家长在“学习设置”中先检测设备端语言包，并完成一次真实环境短测。“设备端”主要解决隐私、延迟和离线能力，并不自动保证比云端模型更准确。

当前版本会向支持的识别器提供目标词及常用英语指令作为上下文偏置，并检查最多五个候选结果。完整的本地识别技术比较、测量指标和后续路线见 [设备端语音识别评估](docs/speech-roadmap.md)。

## 设计原则

1. 学习流程由可测试的确定性状态机驱动，AI 服务不是完成课程的前提。
2. 屏幕用于资料管理、学习设置与必要兜底，孩子的主流程以听和说完成。
3. 内容与引擎分离，官方教材内容由使用者合法导入。
4. 默认最小化儿童数据：不注册、不上传、不保存原始录音。
5. 记忆策略逐步验证后再采用，不承诺未经测量的学习效果。

更多细节见 [系统架构](docs/architecture.md) 与 [学习设计](docs/learning-design.md)。

## 路线图

- v0.1：英语单词音频学习闭环、CSV 导入、本地学习报告。
- v0.2：课程与资料库、资料内容更新、学习范围选择、设备端 Web Speech 语言包管理。
- v0.3：真实儿童语音基准、音频前处理与 VAD、sherpa-onnx/Whisper 本地引擎原型对比。
- v0.3：间隔复习、掌握度模型、匿名且可选择加入的效果评估。
- 后续：扩展到语文、数学、科学、历史、地理等适合听觉回忆的知识点；所有学科仍坚持内容授权与来源可追溯。
